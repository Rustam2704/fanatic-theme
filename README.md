# fanatic — визуальная тема Windows (baseline)

Готовый к повтору набор, чтобы на **любой** Windows 10/11 получить тот же вид:

- звёздное небо вместо обоев — **реальное небо над вашим городом**, линии и названия созвездий, по желанию Млечный Путь;
- чёрная панель задач с большими индикаторами (Wi-Fi/Ethernet + пинг, батарея, звук, раскладка, дата, часы — шрифт Diablo);
- стеклянные меню и флайауты (часы с секундами, календарь, почасовая погода на 24 часа со скроллом, звук, питание);
- свёрнутый трей: на панели только наши значки, остальное в `^`;
- переключатель раскладки UA / RU / EN с индикатором (левый клик — следующая раскладка по кругу, правый — меню);
- интерфейс на **English / Українська / Русский** (переключается на лету, добавить язык = один файл);
- погода для **вашего** места (определяется по IP при первом запуске, кнопка «Обновить местоположение»).

Только внешний вид. Что сознательно не вошло — в конце.

## Главное правило: всё собирается из исходников

В пакете **нет готовых .exe**. Установщик собирает каждую программу встроенным в Windows компилятором .NET.
Раньше рядом с исправленными исходниками лежали старые готовые exe — и на других машинах возвращались давно исправленные
баги. Сборка из исходников гарантирует: запущено ровно то, что лежит в `src\`.

## Требования

| что | зачем | где взять |
|---|---|---|
| Windows 10 (1903+) или 11 | .NET Framework 4.8 и его компилятор `csc.exe` встроены | — |
| **ExplorerPatcher** (проверено: 26100.8457.70.3) | бар встраивается в классическую панель EP; на штатной панели Win11 бар и сворачивание трея **не работают** | https://github.com/valinet/ExplorerPatcher/releases |
| права администратора | задачи с наивысшими правами, экран блокировки (HKLM) | — |
| шрифты Consolas, Bahnschrift, Segoe UI | текст флайаутов и цифры (встроены в Windows; на урезанных Lite-сборках установщик предупредит) | — |
| интернет при первом запуске | погода (open-meteo.com) и место по IP (ipwho.is), оба без ключей | — |

Вид 1:1 — при 1920×1080 и масштабе 125 %; бар подстраивается под высоту панели и DPI.

## Установка

1. Поставьте **ExplorerPatcher** (`ep_setup.exe` с GitHub) и дождитесь, пока панель задач станет классической.
2. Распакуйте архив куда угодно, например `C:\setup\fanatic-theme`.
3. PowerShell **от администратора**, войдя под тем пользователем, у которого будет тема:

```powershell
cd C:\setup\fanatic-theme
powershell -ExecutionPolicy Bypass -File install\install.ps1                  # английский интерфейс, C:\fanatic
powershell -ExecutionPolicy Bypass -File install\install.ps1 -Language ua     # украинский (ua) / ru / en
```

Ключи установщика:

| ключ | что делает |
|---|---|
| `-Language en\|ua\|ru` | язык интерфейса (любой файл `config\strings\<код>.json`) |
| `-Root D:\fanatic` | куда ставить (по умолчанию `C:\fanatic`) |
| `-MsiFan` | **только ноутбуки MSI с управлением вентилятором через EC** (проверено на Thin GF63 12VE): температура CPU, режимы вентилятора, подсветка клавиатуры. На другом железе не включать |
| `-NoLockScreen` | не менять картинку экрана блокировки |
| `-SkipLayouts` | не добавлять раскладки UA/RU/EN в список языков |

4. После установки один раз выйдите из системы и войдите снова.

### Что делает установщик (по шагам — можно повторить руками)

0. Проверки: администратор, компилятор .NET, ExplorerPatcher, шрифты.
1. **Сборка из исходников** всех программ в `<Root>`: `fanatic-bar`, `sky-stars`, `keyboard-switch`, `screen-dim`, `tray-prefs`
   (+ `fan-tray` с `-MsiFan`). Рядом с каждой — её файлы: переводы, значки погоды, каталог звёзд, Млечный Путь, настройки по
   умолчанию (только если настроек ещё нет — повторная установка ваши настройки не затирает).
2. Язык → общий файл `%LOCALAPPDATA%\fanatic\lang.txt` (его читают все программы).
3. Реестр (только внешний вид): тёмная тема и прозрачность, цвет акцента, настройки Проводника и панели, настройки
   ExplorerPatcher, скрыть системные часы/звук/питание (их заменяет бар), скрыть системный индикатор языка.
   **Чёрный фон стола применяется сразу** (без него сквозь небо просвечивают старые обои). Экран блокировки — то же небо.
   Пункт **«Небо…» / «Sky…»** в меню правого клика по рабочему столу (на выбранном языке).
   Системные хоткеи раскладки Windows (Alt+Shift, Ctrl+Shift) **выключаются** — их обрабатывает keyboard-switch, иначе
   раскладка переключалась бы дважды. Раскладки uk / ru / en-US добавляются, если их нет (ничего не удаляется).
4. Автозапуск (задачи по входу в систему): `fanatic-bar` (+3 с), `sky-stars` (+2 с), `keyboard-switch` (+2 с, с наивысшими
   правами — чтобы переключать раскладку и в окнах администратора), `screen-off` (+10 с, **создаётся выключенной**),
   `fanatic-time-sync` (синхронизация времени по кнопке в меню часов, от SYSTEM). С `-MsiFan`: `fan-tray` и задачи `msi-fan*`.
5. Корректный перезапуск Explorer и запуск программ.
6. Трей: наши значки — на панели, всё остальное — в `^`.

## После установки — проверка

- рабочий стол чёрный, по нему идёт звёздное небо;
- на панели большие индикаторы, справа дата и часы;
- правый клик по столу → «Небо…» открывает настройки неба;
- в меню погоды (клик по погоде) — ваш город; если нет — кнопка «Обновить местоположение»;
- Alt+Shift / Ctrl+Shift переключают раскладку, индикатор меняется.

## Настройки

| где | что |
|---|---|
| **ПКМ по столу → «Небо…»** | линии созвездий и их яркость, названия созвездий, **фон подписей** (плашки под названиями), яркость звёзд, **Млечный Путь** и его яркость, **язык** всей темы. Применяется сразу |
| меню погоды → «Обновить местоположение» | место заново по IP. Погода и небо берут одно и то же место: `%LOCALAPPDATA%\fanatic\location.json` |
| `<Root>\fanatic-bar\fanatic-bar.json` | `bigIndicators` (большие индикаторы, по умолч. вкл), `taskbarBlack` (чёрная панель), `gear` (значок «Параметры»), `keyboardBacklight` (строка подсветки клавиатуры в меню батареи — **по умолч. выкл**, нужен `-MsiFan`) |
| `<Root>\sky-stars\sky-stars.json` | то же, что в окне «Небо…» |
| `<Root>\screen-dim\screen-off.json` | `screen-off` гасит экран при попытке убавить яркость ниже минимума. Выключен; включить: `Enable-ScheduledTask screen-off` |

Командная строка (для проверки и отладки):
`fanatic-bar.exe --geo` / `--geo Dublin` — определить место по IP / по названию; `--shot файл.png` — все состояния значков;
`--shot-fly файл.png` — флайауты; `sky-stars.exe --shot файл.png [lines,labels]` — небо; `--shot-settings файл.png` — окно
настроек неба; `--quit` — корректно закрыть бар / небо.

## Переводы

Все надписи — в `config\strings\en.json`, `ua.json`, `ru.json` (плоский JSON «ключ: текст»). Новый язык = скопировать
`en.json` в `<код>.json` и перевести значения — инструкция для человека или нейросети: `config\strings\TRANSLATE.md`.

## Опционально

- **Вентилятор MSI** (`-MsiFan`): температура CPU, режимы Performance / Balanced / Eco, Cooler Boost, подсветка клавиатуры.
  Пишет в embedded controller через BIOS WMI. **Только MSI с совместимым EC.** Скорость вентилятора никогда не задавайте
  ровно 100 % — этот EC тогда останавливает вентилятор.
- **AltSnap 1.68** (двигать окно Alt+перетаскивание, размер Alt+ПКМ): https://github.com/RamonUnch/AltSnap/releases, затем
  положить рядом `config\defaults\AltSnap.ini`. Автозапуск — в его меню трея.
- **Everything** (поиск файлов, https://www.voidtools.com): если он установлен в Program Files, установщик создаёт задачу
  `everything-search`, и **Ctrl+Alt+F** открывает окно поиска. Без Everything сочетание остаётся свободным для других программ.
- `extras\hotkeys-msi-qwertz.html` — шпаргалка по клавишам для MSI с немецкой клавиатурой.

## Хоткеи с whitebook (справочно)

Сочетания, которые владелец добавил себе на whitebook (Linux, i3), и что им соответствует в Windows. Ставить ничего не нужно:
где в Windows есть своё — пользуйтесь им; остального в Windows нет. Alt+Shift, Ctrl+Shift и Ctrl+Alt+F заняты keyboard-switch.

| сочетание | на whitebook | в Windows |
|---|---|---|
| Win+стрелки | развернуть / половина / четверть / свернуть | **есть** (Snap) |
| Win+Shift+←/→ | окно на соседний экран | **есть** |
| Win+Shift+S | скриншот области в буфер | **есть** (Ножницы) |
| Win+E | файлы | **есть** (Проводник) |
| Alt+Tab, Alt+Shift+Tab | переключение окон | **есть** |
| Ctrl+Shift+Esc | системный монитор | **есть** (Диспетчер задач) |
| Win+D / Win+R / Win+Tab | поиск приложений / запуск / список окон | Win+S (поиск), Win+R (выполнить), Win+Tab (представление задач); Win+D в Windows — показать рабочий стол |
| Win+1…9, Win+Shift+1…9 | рабочий стол N / перенести окно на стол N | в Windows Win+1…9 — N-я программа на панели; рабочие столы — Win+Ctrl+←/→, Win+Ctrl+D |
| Win+Shift+V / Win+Alt+V | диктовка EN / UA | **Win+H** (голосовой ввод) |
| Win+F | развернуть / вернуть окно | Win+↑ / Win+↓ |
| Win+− | свернуть окно | Win+↓ |
| Win+Enter | терминал | нет (запуск через Win+R → `wt`) |
| Win+Ctrl+стрелки | размер окна на 40 px | нет (Alt+Space → «Размер») |
| Win+/ | шпаргалка | нет (`extras\hotkeys-msi-qwertz.html`) |
| Win+Shift+E | меню питания | нет (Alt+F4 на рабочем столе) |
| Win+C | light-year (своё приложение whitebook) | нет |

## Типичные грабли

- **Explorer перезапускать только `<Root>\restart-explorer.ps1`.** Он сначала корректно отцепляет бар и небо, закрывает Explorer
  штатно и запускает всё обратно. `taskkill /f explorer` роняет окна неба и может дать «explorer.exe — Unknown Hard Error».
- **Бар и небо закрывать `--quit`, не убивать процесс** — иначе в трее остаются «призраки» значков.
- **Нет больших индикаторов** — не стоит ExplorerPatcher или выбрана штатная панель Win11.
- **Значки и `^`.** Новый процесс программы Windows регистрирует как новые значки со «спрятать в `^`». Бар сам
  каждые 15 с возвращает значки программ fanatic на панель (`TrayPromote.cs`), так что после перезапуска или входа в систему
  большие индикаторы появляются через пару секунд. Вручную: `<Root>\tray-prefs\tray-prefs.exe set 2 fanatic-bar.exe`.
- **ПКМ по столу работает сквозь небо** (оно прозрачно для кликов и лежит под значками). Если ПКМ перестал открываться —
  перезапустите Explorer скриптом выше.
- **Прозрачность меню** — просвечивает только чисто-чёрный фон, текст и кнопки плотные. Сила — константа `GlassTint` в
  `src\fanatic-bar\src\FanaticBar.cs` (`0xB0` ≈ 69 %; `0x99` прозрачнее), потом пересборка.
- **Старые обои под небом** — фон должен быть чёрным: Параметры → Персонализация → Фон → Сплошной цвет → чёрный.

## Пересборка / разработка

`src\<программа>\build.ps1 [-Root C:\fanatic] [-NoStart]` — собирает из исходников и ставит; останавливает и перезапускает
**только** копию по этому пути (одноимённые программы в других местах не трогаются). Общая логика — `src\build-common.ps1`.

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File install\uninstall.ps1 [-Root C:\fanatic] [-RemoveFiles]
```

Убирает задачи, скрытие системных значков, сворачивание трея, пункт «Небо…», картинку экрана блокировки, возвращает
хоткеи раскладки Windows. Тёмная тема, цвет акцента и настройки Проводника остаются — это обычные настройки Windows.

## Состав пакета

| папка | что |
|---|---|
| `install\` | `install.ps1`, `uninstall.ps1`, `tasks\` (шаблоны задач вентилятора MSI) |
| `src\` | исходники всех программ + `build.ps1` у каждой |
| `config\strings\` | переводы EN / UA / RU + `TRANSLATE.md` |
| `config\defaults\` | настройки по умолчанию |
| `assets\` | Млечный Путь, значки погоды, экран блокировки, шрифты-исходники глифов (устанавливать не нужно — глифы вшиты в exe) |
| `registry\` | визуальные настройки Windows (.reg) |
| `extras\` | шпаргалка по клавишам |

## Что СОЗНАТЕЛЬНО НЕ вошло

Пакет проверен поиском по: `craftbox`, `tailscale`, `claude`, `anthropic`, `openai`, `api_key`, `token`, `password`, `secret`,
`bearer`, `ssh-`, приватные ключи, адреса `100.x`, `syncthing` (результат — в конце `CHECKS.md`).

- **ИИ:** Claude Code, его настройки и память, ключи, модели, ChatGPT/Codex, Syncthing «AI».
- **Сеть и доступ:** подключение к серверам, Tailscale, OpenSSH, любые пароли, токены, ключи.
- **Обслуживание системы:** Windows Update, проверки здоровья, драйверы, политики браузеров.
- **Машинные данные:** SID, логи, список значков трея исходной машины, бэкапы.
- **Чужие программы целиком:** ExplorerPatcher, AltSnap — только ссылки и конфиги.
- В исходнике keyboard-switch есть обработка клавиш для окна консоли `claude.exe` (Shift+Enter, вставка картинки). Без
  `claude.exe` она ничего не делает, в сеть не ходит, секретов нет.
