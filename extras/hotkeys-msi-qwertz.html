Раскладка

Alt+Shiftукраинская ↔ последняя из RU / EN
только левый Alt
Ctrl+Shiftрусская ↔ английская
клик по языкуUA → RU → EN → UA по кругу
правый клик по языкуменю языков
После переключения на экране на секунду появляется код раскладки (UA / RU / EN). На клавише написано Strg — это Ctrl.

Fn — громкость и яркость (на стрелках)

Fn+←тише
Fn+→громче
Fn+Endeзвук выкл / вкл
Fn+↑экран ярче
Fn+↓экран темнее
Fn — справа от Alt Gr, между клавишей < > и правым Strg. Значки нарисованы на самих стрелках.

Fn — верхний ряд

Fn + F2второй экран / проектор
Fn + F3тачпад выкл / вкл
Fn + F6камера выкл / вкл
Fn + F10режим «в самолёте»
Fn + F12сон
Fn + F7кнопка MSI Center — программа не установлена, ничего не делает
Функции — по значкам на клавишах этой модели (MSI GF63). Остальные F-клавиши без Fn работают как обычные F1–F12.
