## Полная установка — проверена на тестовой машине 26.10 (переезд со старой версии темы)

`install.ps1 -Language ua -MsiFan` целиком, в интерактивной сессии, поверх старой темы (старые задачи сохранены в XML,
программы старой версии корректно остановлены). Итог: все программы собраны и запущены из `C:\fanatic`, бар, небо с Млечным
Путём, раскладка, температура CPU на месте. Настоящий прогон нашёл два бага, которых по частям не было видно:

1. **`reg.exe import` валил установщик** — в Windows PowerShell 5.1 успешное сообщение reg.exe идёт в stderr и при
   `ErrorActionPreference=Stop` считается ошибкой. Теперь импорт судится по коду возврата.
2. **Значки бара уходили в `^`, большие индикаторы пропадали** — после перезапуска Explorer старый explorer.exe повис без
   окон, и COM-объект трея был недоступен (`REGDB_E_CLASSNOTREG`); к тому же установщик звал `tray-prefs` с повышенными
   правами. Теперь `restart-explorer.ps1` убирает такие повисшие процессы (оболочка к этому моменту уже закрыта, окна папок
   не трогаются), а `tray-prefs` запускается от обычного пользователя.

## НЕ проверено

- Чистая Windows без предыдущей темы (на тестовой машине был переезд; путь «с нуля» отличается только отсутствием старых задач).
- Windows 10: учтён шрифт значков (Segoe MDL2 Assets), на Win10 не запускалось.

## Безопасность (что не должно уйти в чужие руки)

Поиск по всем файлам, включая UTF-16 (`.reg`, XML задач) и метаданные картинок: `craftbox`, `tailscale`, `claude`,
`anthropic`, `openai`, `api_key`, `token`, `password`, `secret`, `bearer`, `ssh-`, приватные ключи, адреса `100.x`/`10.x`/
`192.168.x`, `syncthing`, SID пользователей, пути `C:\Users\…`, e-mail.
Плюс независимая проверка отдельным агентом.

- Секреты, ключи, токены, пароли — нет.
- Имена пользователей, машин, SID, личные пути — нет (только SYSTEM `S-1-5-18`).
- Настройки ИИ и серверов — нет. В keyboard-switch есть обработка клавиш для окна `claude.exe` — без сети и секретов.
- **Найдено и убрано:** в JPEG Млечного Пути (ESO) были личные e-mail, телефоны и адрес фотографа в XMP. Метаданные
  удалены без потери качества (пиксели идентичны), авторство указано в `assets\milkyway\CREDITS.txt` и README.
- Сетевые обращения программ: open-meteo.com (погода, геокодинг), ipwho.is (место по IP), 1.1.1.1 (пинг). Без ключей.
